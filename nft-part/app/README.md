# Скрипт для деплоя и минтинга NFT на Solana Devnet

Этот скрипт позволяет создать коллекцию NFT на Solana Devnet и минтить NFT с разными уровнями редкости. Скрипт использует программу на Rust/Anchor, которая уже задеплоена на Solana Devnet.

## Требования

- Node.js (версия 16 или выше)
- Solana CLI
- Кошелек Solana с SOL на Devnet

## Предварительная настройка

1. Убедитесь, что у вас установлены все зависимости:

```bash
yarn install
```

2. Убедитесь, что у вас настроен кошелек Solana и есть SOL на Devnet:

```bash
solana config set --url devnet
solana balance
```

Если у вас нет SOL на Devnet, можно получить их бесплатно:

```bash
solana airdrop 2
```

## Запуск скрипта

Запустите скрипт с помощью команды:

```bash
ts-node app/nft-deploy-mint.ts
```

## Что делает скрипт

1. Создает коллекцию NFT "Samurai Collection" с метаданными
2. Минтит три типа NFT с разными уровнями редкости:
   - Kojo (Common) - стоимость 0.5 SOL
   - Daimyo (Rare) - стоимость 1 SOL
   - Shogun (Legendary) - стоимость 2 SOL

## Прокси-минтинг

Скрипт использует технику прокси-минтинга для обхода ограничений blowfish. Для каждого минтинга NFT создается временный кошелек, который затем используется для создания NFT. Этот подход помогает избежать блокировки при массовых минтингах.

## Настройка

Вы можете изменить следующие параметры в скрипте:

- `COLLECTION_CONFIG` - конфигурация коллекции (имя, символ, URI метаданных)
- `NFT_CONFIGS` - конфигурация для каждого типа NFT (имя, символ, URI метаданных, цена)
