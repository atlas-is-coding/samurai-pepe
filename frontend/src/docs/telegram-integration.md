# Интеграция с Telegram для квеста

## Настройка Telegram Bot

1. Создайте нового бота через [@BotFather](https://t.me/BotFather) в Telegram:
   - Откройте чат с @BotFather
   - Отправьте команду `/newbot`
   - Следуйте инструкциям для создания бота
   - Сохраните полученный токен бота (API token)

2. Настройте доменное имя для Login Widget:
   - В чате с @BotFather отправьте команду `/setdomain`
   - Выберите вашего бота
   - Укажите URL, полученный от ngrok (например, `https://xxxx-xxx-xx-xx-xx.ngrok.io`)

## Настройка проекта

1. Обновите переменные окружения в файле `.env.local`:
   ```
   TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here
   NEXT_PUBLIC_TELEGRAM_BOT_USERNAME=your_bot_username_without_@
   ```

2. Запустите ngrok для создания туннеля:
   ```
   yarn ngrok
   ```

3. Скопируйте полученный URL (например, `https://xxxx-xxx-xx-xx-xx.ngrok.io`)

4. Обновите URL в настройках бота через @BotFather (см. шаг 2 выше)

## Тестирование интеграции

1. Запустите локальный сервер:
   ```
   yarn dev
   ```

2. Перейдите к квесту №3 в приложении

3. Нажмите на кнопку "Подключить Telegram"

4. Следуйте инструкциям для авторизации через Telegram

## Устранение неполадок

- Убедитесь, что ngrok запущен и туннель работает
- Проверьте, что URL в настройках бота соответствует URL, полученному от ngrok
- Убедитесь, что в .env.local правильно указаны токен и имя бота
- Проверьте логи сервера на наличие ошибок при аутентификации
